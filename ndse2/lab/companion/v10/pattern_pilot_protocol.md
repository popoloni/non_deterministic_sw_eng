# Proposed pattern comparison — no observations
Population: declare a homogeneous class of bounded maintenance changes before assignment.
Contrast: one optional mechanism (for example structured critique) versus the same workflow without it.
Keep constant: authorized intention, repository snapshot policy, allowed effects, independent oracles, acceptance owner and release controls.
Record: task mix, maintainer familiarity, actor effort, elapsed waiting, setup, retries, failures, abandonment, review, accepted output and follow-up rework.
Assignment: preregister the unit and analysis; address within-person carryover and team spillovers. Do not infer causality from an unadjusted before/after.
Stop: predeclare security/authority violations, unacceptable review queue growth and budget exhaustion; do not choose these thresholds after seeing favorable results.
No mandatory control may be omitted to make the experimental arm faster. The four original synthetic tasks rehearse instrumentation, not an effect estimate.
